API (GET): /api/rankings/articles?period=weekly|alltime&limit=20&offset=0; /api/rankings/users?metric=posts|comments|likes&period=weekly|alltime&limit=20&offset=0. Response: { ok: true, period, window: { start, end, computedAt }, items: [ ... ] }. Article item: { rank, post: { id, title, createdAt, user: { id, username, name, image } }, likesCount }. User item: { rank, user: { id, username, name, image }, postsCount, commentsCount, likesCount }. Non-public posts filtered out at read time.
